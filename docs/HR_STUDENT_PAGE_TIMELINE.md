### **Фича 5: Роль HR: История роста студента (таймлайн)**

#### 5.1 Назначение

Показать HR хронологию всех достижений студента, сгруппированную по годам, для оценки карьерной траектории.

#### 5.2 Где отображается

Профиль студента — отдельная вкладка на странице студента - «История роста»

#### 5.3 Функциональные требования (Frontend)

Используется существующий эндпоинт:

`GET /api/hr/candidates/{studentId}`

Ответ уже содержит все достижения студента. Фронтенд должен самостоятельно сгруппировать их по годам и отфильтровать.

Параметры фильтрации (опционально, реализуются на фронтенде без дополнительных бэкенд-запросов):

* по году (из поля `date`)  
* по типу (из поля `type`, значения: `OLYMPIAD`, `CONFERENCE`, `HACKATHON`, `PUBLICATION`, `COURSE`, `VOLUNTEERING`, `GRANT`, `OTHER`)

Визуализация: Таймлайн (вертикальная лента).

* Каждый год — отдельный блок-разделитель.  
* Каждое достижение — строка с:  
  * датой (из `date`)  
  * типом (иконка / текст на выбор)  
  * названием (из `title`)  
  * уровнем (из `level`: `INTERNATIONAL`, `NATIONAL`, `REGIONAL`, `UNIVERSITY`, `SCHOOL`)  
  * статусом верификации (из `verificationStatus`: `VERIFIED` / `PENDING` / `REJECTED`)  
* Цветовая индикация статуса:  
  * `VERIFIED` — зелёный  
  * `PENDING` — жёлтый  
  * `REJECTED` — красный

Интерактив:

* При клике на название достижения открывается модальное окно с деталями: мероприятие, результат, организатор и т.д., уже есть реализовано в системе.

#### 5.5 Источник данных

| Что | Откуда |
| :---- | :---- |
| Список достижений | `GET /api/hr/candidates/{studentId}` → поле `achievements` |
| Детали достижения | из того же объекта |
| Файлы | `GET /api/files/{fileId}` |

### **Фича 6: График активности студента**

#### 6.1 Назначение

Показать динамику развития студента через частоту получения достижений по месяцам.

#### 6.2 Где отображается

В профиле кандидата во вкладке "График активности студента"

#### 6.3 Функциональные требования (Backend)

Используется существующий эндпоинт:

`GET /api/hr/candidates/{studentId}`

Фронтенд рассчитывает активность по месяцам на основе массива `achievements` (поле `date`).

Расчёт:

* Группировка достижений по месяцам  
* Подсчёт количества достижений в каждом месяце  
* Период: последние 12 месяцев (от текущей даты)

Статистика (рассчитывается на фронтенде):

* `totalAchievements` — общее количество достижений за период  
* `trend` — сравнение количества достижений за последние 3 месяца с предыдущими 3 месяцами ( `up` / `down` / `stable`)  
* `trendPercentage` — процент изменения  
* `previousPeriodTotal` — количество достижений за предыдущий период

#### 6.4 Функциональные требования (Frontend)

Визуализация: Линейный график (line chart).

* Ось X: месяцы (последние 12\)  
* Ось Y: количество достижений  
* Точки данных соединены линией

Интерактив:

* При наведении на точку графика — всплывающая подсказка с месяцем и числом достижений

* `Всего достижений: X`  
* Динамика: `▲ На X% больше, чем за предыдущий период` (зелёный) или `▼ На X% меньше` (красный) или `─ Без изменений` (серый)

#### 6.5 Источник данных

| Что | Откуда |
| :---- | :---- |
| Список достижений с датами | `GET /api/hr/candidates/{studentId}` → поле `achievements[].date` |

### **Общие критерии приемки (Definition of Done)**

| № | Критерий |
| :---- | :---- |
| 1 | Таймлайн (фича 5\) корректно группирует достижения по годам |
| 2 | Таймлайн отображает статус верификации цветом |
| 3 | При клике на достижение открывается модальное окно с деталями |
| 4 | График активности (фича 6\) отображает данные за 12 месяцев |
| 5 | При наведении на точку графика появляется всплывающая подсказка |
| 6 | Под графиком отображается сводка с динамикой |
| 7 | Строка сравнения (фича 7\) отображается в ленте талантов |
| 8 | Строка сравнения корректно меняет цвет и текст в зависимости от динамики |
